# 送料計算

商品小計・会員種別・離島かどうかで送料を決め、支払い方法で手数料を決める。

## 入力

| 入力     | 型   | 値                 | 既定値  | 意味           |
|----------|------|--------------------|---------|----------------|
| member   | 選択 | gold, regular      | regular | 会員種別       |
| island   | 真偽 |                    | N       | 離島配送か     |
| subtotal | 整数 |                    | 3000    | 商品小計（円） |
| payment  | 選択 | card, konbini, cod | card    | 支払い方法     |

表に出てこない入力は既定値を使う。

## 出力

| 出力     | 型     | 意味         |
|----------|--------|--------------|
| shipping | 整数   | 送料（円）   |
| fee      | 整数   | 手数料（円） |
| error    | 文字列 | エラーコード |

表の書き方: 「-」= その出力はない。空欄 = この表では決めない（ディシジョンテーブルの答えを使う）。

## ディシジョンテーブル: 送料

| ルール | subtotal          | member  | island | => shipping | => error         | 備考                       |
|--------|-------------------|---------|--------|-------------|------------------|----------------------------|
| R1     | 範囲外下,範囲外上 | -       | -      | -           | INVALID_SUBTOTAL | 金額チェックが最優先       |
| R2     | 有料,無料,高額    | gold    | -      | 0           | -                | ゴールド会員は離島でも無料 |
| R3     | 有料              | regular | N      | 500         | -                |                            |
| R4     | 有料              | regular | Y      | 1500        | -                | 離島は +1,000 円           |
| R5     | 無料,高額         | regular | N      | 0           | -                |                            |
| R6     | 無料,高額         | regular | Y      | 1000        | -                | 無料でも離島料金はかかる   |

条件の「-」はどの値でもよい。subtotal の区間（有料、無料など）は下の境界値の表で決める。

## ディシジョンテーブル: 手数料

| ルール | subtotal          | payment      | => fee | 備考                   |
|--------|-------------------|--------------|--------|------------------------|
| F1     | 範囲外下,範囲外上 | -            | -      | エラー時は手数料なし   |
| F2     | 有料,無料,高額    | card,konbini | 0      |                        |
| F3     | 有料,無料         | cod          | 330    | 代引手数料             |
| F4     | 高額              | cod          | 0      | 1 万円以上は代引も無料 |

## 境界値: subtotal

| 区間     | 最小   | 最大   | => error         | 備考                   |
|----------|--------|--------|------------------|------------------------|
| 範囲外下 |        | 0      | INVALID_SUBTOTAL | 1 円未満は受け付けない |
| 有料     | 1      | 4999   | -                |                        |
| 無料     | 5000   | 9999   | -                | 5,000 円以上で送料無料 |
| 高額     | 10000  | 100000 | -                | 代引手数料も無料       |
| 範囲外上 | 100001 |        | INVALID_SUBTOTAL | 上限 10 万円           |

## 不正な入力

| 入力     | クラス | 値                      | => error         | 備考                   |
|----------|--------|-------------------------|------------------|------------------------|
| member   | 未知   | platinum, "", "GOLD"    | INVALID_MEMBER   | 大文字小文字は区別する |
| member   | 型違い | 1, true, null, (なし)   | INVALID_MEMBER   |                        |
| island   | 型違い | "true", 1, null, (なし) | INVALID_ISLAND   | 文字列の "true" は不可 |
| subtotal | 小数   | 3000.5                  | INVALID_SUBTOTAL |                        |
| subtotal | 型違い | "3000", null, (なし)    | INVALID_SUBTOTAL | 数字の文字列も不可     |
| payment  | 未知   | paypay, ""              | INVALID_PAYMENT  |                        |
| payment  | 型違い | 0, null, (なし)         | INVALID_PAYMENT  |                        |

値の書き方: `gold` = 文字列、`""` = 空文字列、`1` = 数値、`null`、`(なし)` = そのキーを送らない。
書いていない出力は「ない」ものとして検査する。

## 組み合わせ: 有効な入力

| 入力     | 値             |
|----------|----------------|
| member   | すべて         |
| island   | すべて         |
| subtotal | 有料,無料,高額 |
| payment  | すべて         |

どの 2 つの入力を選んでも、値の組がすべて一度は出てくるケースを自動で作る（ペアワイズ）。期待値はディシジョンテーブルから引く。
